## 4. 功能需求

### 4.1 功能结构图

```
智慧教育平台
├── 用户系统：注册 / 登录 / 重置密码 / 个人资料 / 角色
├── 课程资源：筛选 / 排序 / 搜索 / 详情 / 收藏 / 学习进度
│   ├── 理论课程
│   ├── 实训课程
│   └── 认证课程
├── AI 学习助手：智能答疑 / 学习路径 / 作业批改 / 学习报告
├── 实习就业：职位筛选 / 搜索 / 详情 / 收藏 / 申请
└── 后台管理：用户 / 课程上下架 / 讲师 / 订单 / 职位 / 申请
```

### 4.3 核心用例

**UC-01 学生学习课程**

- 参与者：学生
- 前置条件：已登录
- 主流程：进入课程列表 → 筛选"人工智能/初级/免费" → 按评分排序 → 打开详情 → 收藏 → 立即学习 → 完成章节 → 进度更新
- 异常流：未登录点击收藏 → 跳转登录页并回跳；课程已下架 → 详情页提示不可学习

**UC-02 AI 智能答疑**

- 参与者：学生
- 前置条件：已登录，进入 AI 助手
- 主流程：选择课程 → 输入问题 → 返回解答（含知识点拓展）→ 追问保持上下文 → 切换会话
- 异常流：大模型不可用 → 返回 Mock 答案并提示"当前为离线模式"
