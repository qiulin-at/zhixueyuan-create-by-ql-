## 1. 设计概述

| 项目 | 内容 |
|---|---|
| 架构风格 | 前后端分离 + 分层单体（Router → Service → ORM） |
| 技术栈 | FastAPI / SQLAlchemy / MySQL / Vue3 / Vite / Element Plus / Pinia |
| 大模型 | OpenAI 兼容协议（DeepSeek 等），无 Key 自动降级 Mock |

### 1.1 设计原则

- 关注点分离：接口层不写业务逻辑，业务逻辑不写 SQL 拼接。
- 配置外置：数据库、密钥、模型参数全部走环境变量。
- 可降级：外部依赖（LLM）失败不影响主流程。
- 可测试：Service 可独立单测，接口可用 TestClient 集成测。

## 2. 总体架构

```
浏览器(Vue3 SPA)
   │ RESTful + JWT
Nginx ── /api ──► FastAPI
                    ├─ routers（鉴权/课程/AI/职位/后台）
                    ├─ services（业务编排 / LLM 网关 / 规则兜底）
                    ├─ core（配置 / 安全 / 依赖注入）
                    └─ ORM ──► MySQL
                              └─ LLM API（OpenAI 兼容）／Mock
```

### 2.1 模块职责

| 模块 | 职责 | 依赖 |
|---|---|---|
| auth | 注册、登录、密码重置 | users 表、security |
| courses | 筛选排序搜索、详情、收藏、进度、评论 | courses/chapters/favorites/learning_records |
| jobs | 职位列表详情、申请 | jobs/job_applications |
| ai | 答疑、路径、批改、报告 | ai_* 表、LLM 网关、learning_records |
| admin | 用户/课程/订单管理 | 全表 + 角色校验 |

### 2.2 关键设计决策（ADR 摘要）

| 决策 | 备选 | 选择理由 | 代价 |
|---|---|---|---|
| FastAPI 而非 Django | Django/Flask | 自动 OpenAPI、异步、轻量 | 需自建后台管理 |
| SQLAlchemy 双库兼容 | 仅 MySQL | 本地零依赖启动，答辩环境稳定 | 个别 SQL 方言需规避 |
| JWT 无状态鉴权 | Session | 前后端分离天然适配 | 无法主动踢下线（可加黑名单） |
| PBKDF2 自实现 | passlib/bcrypt | 标准库零依赖，规避 Python 3.14 兼容问题 | 需自行保证参数规范 |
| LLM 网关 + Mock | 直连 SDK | 厂商可替换、演示可兜底 | 封装层需维护 |

## 5. 接口设计

### 5.1 规范

- 基路径 `/api`；JSON 请求响应；时间为 ISO8601；分页参数 `page`（默认 1）、`page_size`（默认 12，最大 50）。
- 鉴权：`Authorization: Bearer <JWT>`；401 统一触发前端跳登录。
- 响应：`{code, message, data}`，分页 data 为 `{items, total, page, page_size}`。

## 6. 安全设计

| 威胁 | 措施 |
|---|---|
| 密码泄露 | PBKDF2-SHA256，10 万次迭代，随机盐 |
| 越权访问 | 依赖注入 require_role + 资源归属校验（如教师只能改本人课程） |
| Token 盗用 | HTTPS 传输；JWT 短有效期 + 前端过期跳转 |
| SQL 注入 | ORM 参数化，禁止字符串拼接 SQL |
| XSS | 前端 Markdown 渲染禁用原始 HTML；AI 输出转义 |
| 暴力破解 | 登录失败计数 + 验证码（P1 落地） |

## 7. 性能设计

- 列表查询走覆盖索引，模糊搜索限制字段长度；分页避免 offset 过大（深分页用游标，P2）。
- 课程详情缓存 60s（内存 TTL，P2）。
- AI 接口超时 30s，前端流式显示（P1 用 SSE）。
- 学习人数等计数异步更新，避免行锁（P2）。

## 8. 可观测性

- 日志：请求 ID + 方法 + 路径 + 耗时 + 状态码；异常堆栈入文件 `logs/app.log`。
- 健康检查：`GET /api/health` 返回 db 连通性与 LLM 模式（mock/online）。
- 前端错误：Axios 拦截器统一 Toast，控制台输出 request-id。
