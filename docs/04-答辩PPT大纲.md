## 附录 A：预判问题与答案（不上台，背熟）

1. **为什么选 FastAPI 不选 Django？**
   → 异步 + 自动 OpenAPI + 轻量；后台管理用自建页面替代 Django Admin，符合"前后端分离"考核点。
2. **AI 回答幻觉怎么控制？**
   → System Prompt 约束"不确定就说不知道" + 课程上下文 + RAG Top-3 资料注入，回答附「参考」引用；无资料时不强行引用。
3. **多轮上下文怎么存？**
   → ai_messages 落库，按会话取最近 10 条拼接；超长时按 token 预算截断最早消息。
4. **并发下学习进度会覆盖吗？**
   → 唯一索引 (user_id, course_id) + upsert，前端串行提交。
5. **每个人的真实贡献如何证明？**
   → Git 提交记录 + PR Review + 分工表 + 现场代码走读。
6. **大模型 API 费用如何控制？**
   → 答疑限 300 字输出、上下文截断、缓存重复问题（P2）、演示用 Mock。
