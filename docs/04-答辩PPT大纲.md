## 附录 A：预判问题与答案（不上台，背熟）

1. **为什么选 FastAPI 不选 Django？**
   → 异步 + 自动 OpenAPI + 轻量；后台用自建页面替代 Django Admin，符合前后端分离考核点。
2. **AI 回答幻觉怎么控制？**
   → System Prompt 约束 + 课程上下文 + RAG Top-3 引用；无资料时不强行引用；二期加相似度阈值与反馈闭环。
3. **多轮上下文怎么存？**
   → ai_messages 落库，按会话取最近 10 条；超长按预算截断最早消息。
4. **并发下学习进度会覆盖吗？**
   → 唯一索引 `(user_id, course_id)` + upsert；二期改为事件驱动重算。
5. **二期功能做了吗？**
   → 方案已定稿，功能未实施；PPT 第 14–17 页明确为规划，答辩后按 G1–J2 批次执行。
6. **为什么不用向量数据库？**
   → 课程资料规模小，字符 bigram + TF-IDF 可解释、零额外依赖；二期保留接口，规模上来再换。
7. **学生代码真的执行了吗？**
   → 一期不执行，只做静态点评；二期设计为 Docker 一次性容器受限执行，不可用则降级并标注「未执行代码」。
